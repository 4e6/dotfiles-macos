# Gotcha

* [Hammerspoon watchers and eventtaps must be stored in globals](hammerspoon-watchers-must-be-global.md) - A watcher/eventtap kept in a local variable is garbage-collected and silently stops firing.
* [Option+digit / Option+HJKL hotkeys eat macOS special characters](option-modifier-eats-special-chars.md) - Binding these in Hammerspoon suppresses the Option-key character composition normally on those keys.
